# 💿 Aru 黑胶电台 (Aru Vinyl Station)

> 一款专为 **Aru (PolarisRoom)** 打造的双人共听黑胶唱片机 HTML 卡片小应用，支持网易云音乐真声直连、LRC 滚动歌词、高光歌词标星、双向听歌批注笔谈、电台内实时流式回信（`onText`）、聊天单曲分享卡（`<aru-card>`）以及 Canvas 唱片海报导出。

---

## 一、 功能亮点

| 模块 | 功能说明 |
|---|---|
| **1. 黑胶唱机与真声直连** | 纯手绘 SVG 唱臂与旋转黑胶盘动画；支持网易云音乐歌曲 ID 自动解析直连播放（302 重定向直连网易云官方 CDN，**0 占用 VPS 内存与硬盘**），支持自动记忆每首歌的播放断点 |
| **2. 电台内实时回信信笺 (`onText`)** | 点击「💌 分享给 Ta」或「🎧 让 Ta 放歌」时，无需切回聊天页，唱机下方自动展开流式信笺，**一边听歌一边实时看 AI 逐字打字回信**，写完后再切回聊天页，彻底解决切换页面打断 AI 生成的问题 |
| **3. 批注本双向笔谈** | 在「听歌批注本」写下感想并点击「写下」，自动保存并同步唤醒 AI 调用 `addComment` 工具回写批注，实现电台内异步/实时笔谈 |
| **4. 聊天框 `<aru-card>` 单曲分享卡** | 点击分享后，AI 可在聊天窗口直接渲染出带专辑封面、歌曲信息与红心按钮的 Aru 原生交互卡片 |
| **5. 每日日推自动拾贝** | 支持配置每日首次打开电台自动唤醒 AI 挑选今日网易云日推，也可配合 Aru 主动消息规则实现每天早晨定时上新 |
| **6. 零门槛个性化与 JSON 分享** | 打开右上角 `⚙` 设置面板即可修改电台名称、双方署名、三款主题配色（琥珀暖金 / 玫瑰莓果 / 雾蓝月夜），并支持一键导出/导入歌单 JSON 与生成黑胶分享海报 |

## 二、 快速安装与配置教程

### 方式 A：纯前端直接使用（无需自建服务器）
1. 在 Aru 房间中点击 **新建卡片**，将仓库中的 `index.html` 源码完整粘贴进去并保存。
2. 在 Aru 卡片右上角设置中开启 **工具能力（Tools）**（使 AI 可以调用 `addSong`、`addComment`、`listSongs`）以及 **沙箱联网权限**。
3. 添加歌曲时，直接填入可公开访问的 **MP3 音频直链**，即可直接播放与使用全部批注、海报、分享功能。

### 方式 B：接入网易云音乐 MCP 与真声直连桥（完整体验）
如果你想直接通过网易云歌曲 ID 播放真声、搜歌、拉取滚动歌词并让 AI 自动挑日推：
1. **部署后端桥接服务**：在你的 VPS 上部署 `server/server.py`（基于 MIT 开源项目 `Vael-KY/netease-music-mcp` 扩展了 `/audio`、`/audio_url`、`/lyric`、`/search` 四个只读直连接口）。
2. **配置环境变量**：复制 `server/.env.example` 为 `.env`，填入你自己的 `NETEASE_COOKIE`（切勿将 `.env` 上传至公开仓库）。
3. **绑定反向代理与域名**：使用 Nginx 将 `/netease/` 反代至本地端口（默认 `3456`），开启 HTTPS。
4. **修改卡片接口地址**：在 `index.html` 中找到 `const API_BASE = "https://your-netease-api.example.com/netease";`，替换为你自己的域名即可。

## 三、 ⚠️ 已知平台限制、安全隐患与使用建议（必读！）

为了让你在使用和二次分享时既顺畅又安全，请务必了解以下底层机制与注意事项：

### 1. 平台与 iOS 系统限制（非 Bug，属底层沙盒机制）

| 现象 | 底层原因 | 最佳实践与建议 |
|---|---|---|
| **切回聊天页面时音乐会暂停** | Aru 的 HTML 卡片运行在独立的 WebView 容器中；当收起卡片回到聊天主界面时，容器会被系统挂起省电，导致 `<audio>` 暂停 | 1. 电台已内置 **断点记忆（每 2 秒自动保存进度）**，再次点开会从停住的那一秒继续唱；<br>2. 点击「分享」或「写批注」后，**请停留在电台页面看唱机下方的实时回信框（`onText`）**，等提示「✅ 已写完」后再切回聊天，既能听完整首歌，又不会打断 AI 回复；<br>3. **锁屏状态或切换到其他 App 时**，音乐可以正常在后台继续播放 |
| **iOS 锁屏控制中心不显示封面与歌名（灰白方块）** | 虽然代码已完整接入 `MediaSession API`，但 iOS 规定内嵌 `WKWebView` / `iframe` 沙盒内的网页元数据需宿主 App 原生层开启 `MPNowPlayingInfoCenter` 桥接才能投射到锁屏 | 锁屏界面目前仅用于 **后台听声与暂停/继续控制**；查看黑胶旋转封面、滚动歌词与批注请直接在电台卡片内欣赏 |
| **部分网易云歌曲点击后无声** | 灰掉无版权的旧版链接或部分仅限客户端加密播放的音源无法返回直链 | 在电台「＋ 加歌 → 搜歌」中重新搜索该歌曲的其他可用版本（如 Live 版或重制版）替换即可，或点击「🎵 去网易云听」一键跳转 App |

### 2. 隐私与安全隐患提醒（开源/分享前必查！）

| 风险点 | 隐患说明 | 防护措施 |
|---|---|---|
| **1. 严禁泄露 `NETEASE_COOKIE`** | 后端的网易云 Cookie 拥有你账号的歌单读写权限，一旦写死在代码里推上 GitHub，别人就能操控你的网易云账号 | 永远只把 Cookie 放在 VPS 的 `.env` 文件里，并确保 `.gitignore` 已忽略 `.env` |
| **2. 私人反代域名 (`API_BASE`) 暴露风险** | 如果把写死自己 VPS 域名的 HTML 直接公开分享，所有人都会走你的 VPS 接口请求音源，可能触发网易云 IP 频控限制 | **公开分享 HTML 时，请使用本仓库的脱敏版**（已将 `API_BASE` 设为示例地址 `https://your-netease-api.example.com/netease`），或在自己的 Nginx 上配置简单的访问限流 (`limit_req`) |
| **3. 默认歌单与私密批注泄露** | 自己日常使用的卡片状态与 `DEFAULT_SONGS` 里往往包含伴侣真名和私密悄悄话 | 使用卡片分享功能时，可勾选/取消勾选 `shareContent` 中的歌单与批注；推送到 GitHub 公开仓库时，请使用已清除私人署名的通用版模板 |
